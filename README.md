# CloudTrack

CloudTrack is a portfolio-grade project management system for learning full-stack engineering and low-cost Azure delivery.

## Planned stack

- Angular 22 and Angular Material
- ASP.NET Core .NET 8 Web API
- Entity Framework Core with SQLite locally and PostgreSQL in Azure
- JWT authentication with rotated refresh tokens and role-based authorization
- xUnit unit/integration tests and Playwright end-to-end tests
- GitHub Actions, Docker, and Azure infrastructure-as-code

The repository is intentionally built in small, verified commits so its history documents the engineering decisions.
